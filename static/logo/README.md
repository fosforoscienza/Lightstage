# Loghi Brown Enterprises srls

In questa cartella vanno i loghi PNG usati nei crediti in fondo
all'interfaccia. I nomi dei file devono restare questi:

| File | Uso |
|------|-----|
| `brown-enterprises-bianco.png` | tema scuro (quello attuale dell'app) |
| `brown-enterprises-nero.png`   | versione per sfondi chiari (stampa, documenti) |

Per aggiornare un logo basta sostituire il file (stesso nome) e fare
commit: PNG con sfondo trasparente, proporzioni libere — in pagina viene
mostrato alto 16 px.

I file attuali provengono dal progetto BOOKLET.
